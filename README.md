# TikTok-система совместного обучения

Бесплатная обучающая игра: каждая миссия заканчивается реальным опубликованным видео.
Цикл: обучение → практика → обратная связь → измерение → улучшение (Изучить → Гипотеза → Сделать → Проверить).
Бесконечная система блоками по 4 недели.

Статичный сайт (index.html, styles.css, app.js). Данные — в localStorage браузера, перенос — экспорт/импорт JSON.
Обмен оценками «дай 3 — получи 3» в этой версии ведётся вручную; автоматический обмен требует сервера.

Публикация: GitHub Pages из ветки main, корень репозитория.
